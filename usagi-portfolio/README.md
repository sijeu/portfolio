# Usagi’s Pastel Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript. Usagi illustrations are PNG image assets cropped from the supplied reference screenshot; they are not drawn in markup or styles.

## Open it

Open index.html in a browser. Google Fonts load when an internet connection is available; system font fallbacks are included.

## Files

- index.html — page structure and content
- styles.css — colors, layout, responsive styles, and dark theme
- script.js — mobile navigation, theme toggle, and section highlighting
- assets/ — cropped Usagi PNG assets
- projects/ — local copies of the projects linked from the featured project cards

## Personalize

Update project descriptions and contact links in index.html.
